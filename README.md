# TaiAri

STREET FIGHTER 6 の戦績を集めて、配信画面に出すための Windows 用ツールです。
CAPCOM の公式戦績サイト **Buckler's Boot Camp** に自分のアカウントでログインし、
対戦の記録を手元に貯めながら、OBS に重ねるオーバーレイと文字だけの出力（テキストファイル）を作ります。

**[最新版のダウンロードはこちら（Releases）](https://github.com/Bansho0000/TaiAri_Release/releases/latest)**

> TaiAri は個人が作った非公式のツールです。株式会社カプコンとは関係がありません。

---

## TaiAri の考え方

TaiAri は「配信中に、いま何が起きているかを見ている人に伝える」ための道具です。

- **見せたいのは「今」の状況。** オーバーレイの初期状態には、今回の戦績・MR とその推移・目の前の対戦相手・
  連勝の勢いを並べています。表示する項目は自由に足したり外したりできます。
- **取り込んだらすぐ画面に出す。** 新しい戦績を取り込んだその時に、OBS のオーバーレイへ反映します。
- **手元の PC の中だけで完結させる。** TaiAri が立てるサーバーは自分の PC からしかつながりません。
  同じネットワークの他の機器やスマートフォンからは見えません。
- **どこにも何も送らない。** 通信するのは Buckler と、更新の確認・ダウンロードとキャラクター情報の取得に使う
  GitHub だけです。開発者のサーバーはありません。ユーザーコードや戦績、使い方の記録を送ることもありません。
- **ログイン情報は暗号化して手元に置く。** ログインは Buckler の画面でそのまま行い、TaiAri はパスワードを
  受け取りません。ログイン後の情報は Windows の機能で暗号化して保存し、同じ PC の同じ Windows ユーザーでしか読めません。
- **Buckler に負担をかけない。** 戦績の確認は 45 秒ごと（設定で 30 秒・15 秒にも変えられます）です。
  ゲーム本体のメモリやファイルには一切触りません。
- **すべての機能を無料で使える。** ライセンス認証や有料の機能はありません。

## 動作環境

| 項目 | 内容 |
| ---- | ---- |
| OS   | Windows 10（21H2 以降）／ Windows 11（64 ビット） |
| 必要なもの | Microsoft Edge WebView2 ランタイム（Windows 11 と最近の Windows 10 には最初から入っています） |
| アカウント | STREET FIGHTER 6 をプレイしている CAPCOM ID（Buckler's Boot Camp にログインできること） |

Chrome などのブラウザーを別に入れる必要はありません。

## はじめかた

1. [Releases](https://github.com/Bansho0000/TaiAri_Release/releases/latest) から `TaiAri_{バージョン}.zip` をダウンロードします。
   （同じページにある `.zip.sig` は自動更新で使うファイルです。ダウンロードしなくてかまいません）
2. ZIP を**書き込みできる場所**に展開します（例: `ドキュメント\TaiAri`）。
   `Program Files` の中に置くと、設定や戦績を保存できずに起動できません。
3. 展開したフォルダの中の `TaiAri.exe` を起動します。
4. 初回はウィンドウの中に Buckler のログイン画面が出るので、いつもどおりログインしてください。
5. 設定 →「キャラクター名と ACT の情報」の「更新」を押して、キャラクター名などを取り込みます。

起動時に「Windows によって PC が保護されました」と出た場合は、「詳細情報」→「実行」を押してください。
個人で配布しているソフトに出やすい表示です。

## OBS で使う

1. TaiAri の「オーバーレイ」画面で URL（`http://127.0.0.1:{番号}/overlay/?preset=1`）をコピーします。
2. OBS に**ブラウザソース**を追加して URL を貼り付け、幅と高さを画面の案内どおり（既定は 1920 × 1080）にします。
   背景は透明なので、クロマキーは要りません。
3. デザインを複数作った場合は、URL の `preset=` の数字で切り替えます。
4. 文字だけを出したいときは、オーバーレイ画面の「テキスト出力のフォルダ」から `.txt` ファイルを
   OBS のテキストソースへドラッグ＆ドロップします（LP、MR の増減、対戦相手の名前など 11 種類）。

TaiAri を起動している間だけオーバーレイが表示されます。配信の前に TaiAri を起動しておいてください。

## アップデート

新しいバージョンが出ると、TaiAri の画面の上に知らせが出ます。
**「更新して再起動」を押すと、ダウンロード・入れ替え・再起動を自動で行います。**
設定と戦績はそのまま残ります。ダウンロードしたファイルは開発者の署名を確かめてから使うので、
改ざんされたファイルで置き換わることはありません。

- 再起動のあいだ（数秒から数十秒）、OBS のオーバーレイは表示が止まります。配信中の更新は避けてください。
- 知らせは起動時に確認します。すぐ確かめたいときは、設定 → アップデートの「今すぐ確認」を押してください。

### 自動で更新できないとき

書き込みできない場所に置いている場合などは「更新して再起動」が出ず、「配布ページを開く」だけが出ます。
その場合は次の手順で更新してください。

1. TaiAri を終了する
2. [Releases](https://github.com/Bansho0000/TaiAri_Release/releases/latest) から新しい ZIP をダウンロードして展開する
3. 中の `TaiAri` フォルダの内容で、今のフォルダを上書きする
   （**`data` フォルダはそのまま残してください。** 設定と戦績が入っています）
4. `TaiAri.exe` を起動する

## 保存されるデータ

TaiAri が保存するものは、すべて `TaiAri.exe` と同じ場所の `data` フォルダに入ります。
それ以外の場所（レジストリなど）には何も書きません。

| フォルダ           | 内容                                                      |
| ------------------ | --------------------------------------------------------- |
| `data\auth\`       | ログイン情報（暗号化済み。同じ Windows ユーザーでしか読めない） |
| `data\db\`         | 対戦の記録と、終わった ACT の最終成績                     |
| `data\config\`     | 設定と画面の表示状態                                      |
| `data\overlay\`    | オーバーレイのデータとデザイン                            |
| `data\obs_text\`   | OBS のテキストソース用のファイル                          |
| `data\log\`        | 動作の記録。ログイン情報は書きません                      |

- **別の PC へ移すとき**は、フォルダごとコピーしてください。ただしログイン情報は暗号化の都合で移せないので、
  移した先でもう一度ログインします。
- **データを消したいとき**は、設定 →「全データの削除」で、ログイン情報を含めてまとめて消せます。

## アンインストール

展開したフォルダを丸ごと削除するだけです。

## うまくいかないとき

| 起きたこと | 試すこと |
| ---------- | -------- |
| ウィンドウが開かない | [Microsoft Edge WebView2 ランタイム](https://developer.microsoft.com/microsoft-edge/webview2/) の「Evergreen Standalone Installer」を入れる |
| 起動してもすぐ消える | `Program Files` など書き込みできない場所に置いていないか確かめる。`data\log\app.log` に原因が書かれていることがある |
| 「Windows によって PC が保護されました」と出る | 「詳細情報」→「実行」を押す |
| ウイルス対策ソフトに止められる | 公式の Releases からダウンロードしたものであれば、ウイルス対策ソフトの除外設定に TaiAri のフォルダを追加する |
| ログインが切れたと表示される | TaiAri を再起動して、もう一度ログインする |
| 戦績が更新されない | Buckler's Boot Camp が混み合っている・メンテナンス中のことがある。しばらく待つと自動で再開する |
| キャラクター名が表示されない | 設定 →「キャラクター名と ACT の情報」の「更新」を押す |
| 自動更新のあとに起動しない | `data\log\updater.log` を確かめる。元のバージョンは `data\update\backup\` に残っているので、中身を `TaiAri.exe` のあるフォルダへ戻す |

## このリポジトリについて

| 場所 | 内容 |
| ---- | ---- |
| [Releases](https://github.com/Bansho0000/TaiAri_Release/releases) | 配布している ZIP と、自動更新で使う署名ファイル（`.zip.sig`） |
| `master/character.json` | キャラクター名の一覧（設定 →「キャラクター名と ACT の情報」の「更新」で取り込まれます） |
| `master/act.json` | 各 ACT の期間 |

`master` フォルダのファイルは、新しいキャラクターの追加や ACT の切り替わりに合わせて更新します。
アプリを更新しなくても、設定の「更新」で最新の情報を取り込めます。
